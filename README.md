# 🎬 MovieExplorer

This is my Assignment 2 project. I made a simple Movie Explorer app with React.

Home page has navbar, hero banner and footer. Movies page has search bar.
Click See Details to see full info in a modal.

## Features
- Home page with navbar, hero and footer
- Movies page with search bar (search by title)
- Movie cards (poster, title, rating, year, See Details button)
- Movie details modal (close with ✕ button or clicking outside)
- Responsive grid (4 column desktop, 2 tablet/mobile, 1 small phone)
- Data from TVMaze free API

## API Used
- All shows: `https://api.tvmaze.com/shows`
- Search: `https://api.tvmaze.com/search/shows?q=girls`
- Docs: https://www.tvmaze.com/api

## How to run

```
npm install
npm run dev
```
Then open http://localhost:5173

## Pages
- `/` - Home
- `/movies` - Movie listing + search
